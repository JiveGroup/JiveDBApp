# JiveDB 1.0.0

One client for all your databases — PostgreSQL, MySQL, SQLite, and Redis in a single lightweight native app.

## New Features
- Multi-database connection management with a schema tree (tables, views, routines, sequences, object types).
- SQL editor: schema-aware autocomplete, query history, run the selected statement (⌘/Ctrl+R).
- Data grid: server-side filter/sort, add rows via a validated form, export to CSV/JSON.
- Table structure editor and entity-relationship diagram (ERD).
- Multi-provider AI assistant (OpenAI / Anthropic / DeepSeek / Gemini / Ollama…): generate, explain, and optimize SQL; ask your data.
- Light/dark themes with accent colors; bilingual English / Vietnamese.
